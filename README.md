# Machine Learning Approaches for Predicting Translation Efficiency from Coding Sequences

**Bachelor's Thesis — Computer Science**
**Author:** Helena Floreani

## Abstract

 Ribonucleic acid (RNA) plays an essential role in gene expression. One important type of RNA, messenger RNA (mRNA), serves as the template for protein synthesis. Translation efficiency measures how well an mRNA transcript is translated into protein and is influenced by a variety of factors, including sequence characteristics, transcript-specific regulatory elements, and the cellular environment. Predicting translation efficiency accurately helps us understand gene regulation and supports the development of RNA-based therapeutics.
  
  This thesis explores how to predict translation efficiency from mRNA sequence data using machine learning. First, a dataset of human endogenous transcripts was analyzed to examine translation efficiency values and biologically relevant sequence characteristics. Several biologically motivated sequence-derived features were extracted from the transcripts, including nucleotide composition, codon usage, Codon Adaptation Index, GC content, GC3 content, and sequence length.

  Traditional machine learning models, including linear regression and LightGBM, were trained using biologically motivated sequence-derived features. In addition, embeddings generated by a pretrained RNA language model were used as input features for prediction. Finally, the pretrained RNA language model was directly adapted to the translation efficiency prediction task through fine-tuning. The performance of all approaches was evaluated and compared.
  
  The handcrafted feature-based LightGBM model had the best performance among the models we developed in this study ($R^2 = 0.504$). The top embedding-based model reached an $R^2$ of 0.432. Still, neither model matched the RiboNN baseline, which achieved $R^2 = 0.584$ for LightGBM and $R^2 = 0.600$ for the deep neural network on the same test set. The fine-tuned RiNALMo model performed much worse.
  
  Overall, these results show that carefully designed sequence-derived features remain highly competitive for translation efficiency prediction. At the same time, the strong performance of the RiboNN deep neural network demonstrates that specialized deep learning models trained directly on sequence data can provide additional predictive value. In the evaluated experimental setup, RiNALMo embeddings and the fine-tuned RiNALMo model did not match the performance of the feature-based approaches. Nevertheless, pretrained RNA language models remain a promising research direction, and future work should investigate alternative pretrained models and more extensive fine-tuning strategies.
